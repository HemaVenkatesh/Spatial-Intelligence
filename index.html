Abstract

OYO's rapid expansion across India created a critical challenge: how to optimally cluster properties to maximize profitability while minimizing operational overhead. Existing clustering was manual, inconsistent, and failed to account for spatial demand patterns, competitive density, and property-level performance signals.

This project developed a first-of-its-kind Cluster Recommendation Engine at OYO, combining Text Mining (extracting signals from 10,000+ property listings via web scraping) with Geo-Analytics (spatial demand modeling, competitive benchmarking, and location intelligence) to generate data-driven cluster recommendations. The engine improved profitability by 50% across deployed clusters and became a foundational tool for OYO's expansion strategy.

I. Problem Statement

OYO Frontier businesses faced a supply-demand mismatch at the cluster level — properties were grouped based on legacy administrative boundaries rather than actual demand patterns, competitive landscape, and guest behavior. This led to:

  • Sub-optimal pricing: Properties in high-demand micro-markets priced at par with low-demand zones
  • Inefficient sales deployment: 500+ sales workforce allocated without spatial demand intelligence
  • Lease cost overruns: New property acquisitions without location-level benchmarking
  • Revenue leakage: Cluster-level P&L obscured property-level profitability drivers
Key Question: Can we build a data-driven system that recommends optimal property clusters by combining spatial demand signals, competitive intelligence, and property-level text features — to maximize profitability?

IV. Text Mining Pipeline

A key differentiator of this engine was the integration of unstructured text data from 10,000+ PG and competitor listings, scraped and processed to extract competitive intelligence signals.

Pipeline Steps

  1. Web Scraping: Automated extraction of property listings, amenities, pricing, and reviews from competitor platforms
  2. Text Preprocessing: Tokenization, stopword removal, lemmatization of listing descriptions and reviews
  3. Feature Extraction: TF-IDF vectorization for amenity categorization; sentiment scoring for review analysis
  4. Classification: Property type classification (budget / mid-range / premium) based on text features
  5. Benchmarking: Price-amenity scoring to identify over/under-priced properties relative to cluster peers
Innovation: This was the first time at OYO that unstructured text data from competitor listings was systematically converted into structured features for spatial clustering — enabling a competitive intelligence layer that pure transactional data couldn't provide.

V. Geo-Analytics Engine

The Geo-Analytics component provided the spatial intelligence layer, modeling demand as a function of location attributes.

Location Intelligence Features

  • Demand Generators: Proximity to airports, railway stations, IT parks, universities, hospitals, tourist attractions
  • Competitive Density: Number of competing properties within 1km / 3km / 5km radius
  • Accessibility Score: Transit connectivity, road network density, ride-hailing availability
  • Micro-Market Classification: Commercial, residential, transit hub, tourist zone, mixed-use

This location intelligence platform was also independently deployed to reduce lease costs by 30% — by benchmarking proposed lease rates against spatial demand potential and competitive pricing within the micro-market.
